# chronopix

Vibe coded, pixel-based environments intended to train / test temporal AI architectures. Will feature various degrees of challenge, re: temporal credit assignment and state tracking, while remaining low dimensional and minimalistic.

Frames are just numpy arrays.

<p align="center">

  <img src=".github/gifs/bounce_basic.gif" alt="Bounce environment, simple">
</p>


## Current Environments

* **Bounce**: A box bouncing around the environment a la DVD logo animation.
*  **Scroller**: A simple procedural side scroller.


## Other Features

* **Viewer**: Truthfully, untested.


## Installation

```
# Clone repo
git clone https://github.com/PerfectPickle/chronopix
cd chronopix

# Activate a Python 3.12 environment (e.g. pc-nox)
conda activate pc-nox

# Install the package locally
pip install .
```
